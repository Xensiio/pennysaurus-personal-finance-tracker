TECHNOLOGY STACK:

Backend: Node.js and Express
Database: MySQL/MariaDB for local development; TiDB Cloud Serverless for deployment
API: Express JSON REST API called from the browser using Fetch API

MODERN/EDGE FEATURES:
1. Responsive layout for desktop, tablet, and mobile.
2. Interactive cash-flow and report charts.
3. Session-based authentication with CSRF protection and rate-limited sign-in.
